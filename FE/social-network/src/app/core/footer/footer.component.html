This project is a full-stack social networking platform inspired by Instagram, developed using Angular for the frontend and .NET for the backend. Social Network supports:

  • Follow System: Users can follow and unfollow other users.
  • Post Management: Users can upload and share image-based posts.
  • Likes: Users can like posts.
  • Comments & Replies: Users can comment on posts and reply to other comments, supporting nested conversations.
  • Feed: Personalized feed displaying posts from followed users.
